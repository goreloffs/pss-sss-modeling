# PSS/SSS Generator & Detector (3GPP LTE)

Учебный проект на Python для моделирования первичного (PSS) и вторичного (SSS) сигналов синхронизации в нисходящем канале LTE (3GPP TS 36.211, разделы 6.11.1 и 6.11.2).

Проект демонстрирует генерацию сигналов, их свойства корреляции, устойчивость к шуму и фазовым сдвигам, а также работу приёмника с оценкой и коррекцией частотного сдвига.

## 🚀 Возможности

- ✅ Генерация последовательностей **PSS** (Zadoff-Chu) для `N_ID_2 ∈ {0, 1, 2}`
- ✅ Генерация последовательностей **SSS** (на основе m-последовательностей) для `N_ID_1 ∈ [0, 167]`
- ✅ Кросс-корреляционный анализ PSS (свойство низкой взаимной корреляции)
- ✅ Анализ устойчивости к фазовым сдвигам и аддитивному белому гауссовскому шуму (AWGN)
- ✅ Моделирование приёмника PSS с определением `N_ID_2`
- ✅ Оценка и компенсация частотного сдвига
- ✅ Визуализация ресурсной сетки (6 RB, Normal CP, FDD, субфрейм 0)
- ✅ Наглядные графики созвездий, корреляций и фаз
